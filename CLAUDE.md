## What it is

Tiny zero-dependency TypeScript utility published to public npm as `@mixmaxhq/invoke-fraction`: a single default-exported function `partitionFraction<T>(handlers: Array<[number, () => T]>, defaultHandler?: () => T): T` that randomly invokes one handler per call according to fractional weights (e.g. route 10% of calls to a new code path; fraction `0` disables a handler). Dormant — last published 2021 (v2.0.0, the TypeScript migration) and no in-org consumers found.

## serves

role: weighted random call partitioning — pick one of N callbacks per invocation by fraction (percentage rollouts / traffic routing)
